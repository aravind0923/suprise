RADHI'S BIRTHDAY SURPRISE WEBSITE

1. Keep index.html and the assets folder together.
2. Open index.html in a modern browser to preview.
3. Passcode: 2004
4. Music: The supplied Dheema instrumental starts after the correct passcode is entered, loops continuously, and is set to 45% volume. The Music button can pause/resume it.
5. All nine supplied photos and the music file are included in assets/.

DEPLOY WITH GITHUB PAGES
- Create a new GitHub repository (for example: radhi-birthday-surprise).
- Upload index.html and the complete assets folder.
- In repository Settings > Pages, choose Deploy from a branch, select main and / (root), then Save.
- Wait for GitHub Pages to publish and share the generated site URL.

PRIVACY NOTE
This is a front-end passcode screen, not secure authentication. Anyone with the site files can inspect the code and photos. Do not use it to protect sensitive information.
